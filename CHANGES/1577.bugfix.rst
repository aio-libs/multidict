An object whose ``__length_hint__()`` reports close to
:data:`sys.maxsize` no longer makes ``extend()``, ``update()`` or
``merge()`` of the C extension raise :exc:`SystemError` when keyword
arguments are also passed, or overflow the table size computation;
a hint too large to reserve for is now ignored, as :meth:`list.extend`
does -- by :user:`asvetlov`.
