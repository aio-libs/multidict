The CI test matrix no longer re-tests the macOS and Windows wheels that
cibuildwheel has already tested, cibuildwheel skips the benchmark bodies
and, outside release tags, tests only the ``cp314`` and ``cp314t`` x86_64 macOS
wheels under Rosetta. Debug and pure-Python test jobs now start without
waiting for the wheel builds, and the ``windows-11-arm`` wheel build is
again limited to release tags -- by :user:`asvetlov`.
