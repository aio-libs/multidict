Updating a multidict from a positional argument no longer discards a
:exc:`MemoryError` or :exc:`KeyboardInterrupt` raised by that
argument's ``__len__`` while the size of the update is estimated.
``extend()``, ``update()`` and ``merge()`` now propagate it, matching
the pure-Python backend; only the :exc:`TypeError` from an unusable
``__length_hint__`` is still ignored -- by :user:`asvetlov`.
